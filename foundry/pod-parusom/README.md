# Установка и обновление через GitHub

Весь модуль и все 81 анимация входят в один установочный ZIP. Доступ к папкам сервера не нужен.

1. Завершите запущенный мир и откройте экран настройки Foundry.
2. В разделе дополнительных модулей нажмите проверку обновления у «Под парусом на костылях» и установите версию 1.2.1.
3. При новой установке откройте «Установить модуль», вставьте Manifest URL и нажмите «Установить»:

https://raw.githubusercontent.com/Zajor-DND/Ogm-history/main/foundry/pod-parusom/module.json

4. После установки запустите прежний мир, включите модуль и Midi-QOL. Sequencer используется прежними эффектами приключения. Обновите страницы мастера и игроков.

Для подключения анимаций повторно импортировать NPC и сцены не требуется. В сборке сохранены их прежние ID. Подключение клипов и исключения описаны в INSTALL_1.2_RU.md. Первый тест: патрульный ГК-ЧП применяет «Мушкет», изображение проигрывает один клип и возвращается к статике. Проверьте наблюдение из окна игрока.

Сборка прошла 40 программных проверку; живой тест в Foundry 14.369 / dnd5e 6.0.6 не выполнен.



Поворот к цели и отключение старых снарядов: см. CHANGELOG_1.2.1_RU.md.
